Interactive E-commerce Sales and MTD Dashboard in Power BI

Turned raw sales data into an interactive dashboard that shows how the business is performing right now.

The problem

An e-commerce business needs to know how sales are going, but the data sits in spreadsheets and exports. Checking performance means manual work, and comparing months, products, and categories is slow.

What I did

I cleaned and structured the sales data, then built an interactive Power BI report with a main sales dashboard and a dedicated Month-to-Date (MTD) report page. I designed it around the questions a sales team asks every week: what is selling, what is not, and how is this month tracking?

What you can see at a glance

  • Revenue by category. In this sample data, laptops bring in the largest share, about 31%.
  • Revenue by month. A trend line that makes ups and downs easy to spot.
  • Product filter. Pick any product and the whole page updates.
  • Lost revenue and average order value by category, side by side with revenue.
  • Ratings by category and by state, so weak spots are easy to find.

Key features

  • Revenue, lost revenue, and average order value by category
  • Monthly revenue trend and ranked top products
  • Product filter that updates the whole dashboard
  • Customer ratings by category and by state (map)
  • Sales totals per category at a glance
  • Separate Month-to-Date (MTD) report page

Business value

  • Replaces manual sales reporting with one place to check performance
  • Makes month-to-month comparison quick
  • Shows which products, categories, and regions drive sales
  • Makes complex data easier to understand for non-technical people

Deliverables

  • Complete Power BI report (.pbix)
  • Dashboard preview image
  • Data prepared and ready for reporting

MySQL Employee Database: Structured, Connected, and Ready to Query

Designed a clean, connected database and used SQL to turn stored records into answers.

The problem

Employee and business records often live in separate spreadsheets. Information gets duplicated and goes out of date, and simple questions like "how many people are in each department?" take too long to answer.

What I did

I designed a relational employee database from scratch. I planned the tables, defined primary and foreign keys, and connected everything so the data stays consistent. Then I wrote SQL queries to add, update, retrieve, and analyze the data.

Key features

  • Relational design with multiple linked tables
  • Primary and foreign keys to keep data accurate
  • CRUD operations: create, read, update, delete
  • JOIN queries that combine information across tables
  • Aggregations for summaries and reporting

Business value

  • One organized source of truth instead of scattered files
  • Fewer duplicate or inconsistent records
  • Fast answers to common business questions
  • A solid base that can feed Power BI or Excel reports later

Deliverables

  • Database structure and SQL scripts
  • Sample data and tested queries
  • Query examples for common reporting questions

Excel Data Cleaning and Analysis: From Messy Data to Clear Reports

Cleaned and structured messy data so the numbers can finally be trusted.

The problem

Spreadsheets fill up with duplicates, mixed date formats, and crammed columns. Reports built on that data are slow to make and easy to get wrong, and nobody is sure the totals are right.

What I did

I cleaned the raw dataset step by step: removed duplicates, standardized dates, and split combined data into separate columns. Then I built the analysis with Excel formulas and added data validation so the same problems do not come back.

Key features

  • Duplicate removal and consistency checks
  • Standardized date formatting
  • Combined fields split into clean columns
  • XLOOKUP, SUMIFS, COUNTIFS, and FILTER for analysis
  • Data validation, sorting, and filtering

Business value

  • A clean dataset you can trust for reporting
  • Less time spent fixing and re-checking numbers
  • Analysis that updates as your data changes
  • A file that is ready to reuse or load into Power BI

Deliverables

  • Cleaned and structured Excel workbook
  • Analysis sheet with formulas and summaries
  • Data validation applied where needed
